# B105_Applied_Stat

# The Relationship Between Advertising Spending and Sales — Analysis in R

project investigating how spending on TV, radio and newspaper
advertising relates to product sales across 200 markets, and how a fixed
advertising budget should be allocated across channels, using the
"Advertising" dataset (James et al., 2013).

## Contents
- `data/Advertising.csv` — raw dataset (200 markets, 4 variables: TV, radio,
  newspaper spend and sales)
- `scripts/ad_sales_analysis.R` — full, commented analysis script
- `outputs/` — generated figures, cleaned dataset, descriptive/correlation
  statistics and model summaries produced by the script
- `report/` — final PDF report
